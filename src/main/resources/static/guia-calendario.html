Cómo Usar el Calendario

Formas de Acceder

El calendario puede accederse de varias formas:

1. URL Directa

http://localhost:8080/calendario.html

2. Desde una Rama Específica

http://localhost:8080/ramas/1/calendario

El parámetro ramaId=1 se pasa automáticamente

3. Con Filtro de Persona

http://localhost:8080/calendario.html?personaId=5

Muestra solo eventos relacionados con la persona 5

4. Con Ambos Filtros

http://localhost:8080/calendario.html?personaId=5&ramaId=2

Sistema de Filtros

Filtro por Rama

  • Selecciona una rama del desplegable
  • Las ramas se cargan automáticamente desde /api/ramas
  • "Todas las ramas" muestra eventos de todas
  • El cambio se refleja instantáneamente

Filtro por Tipo de Evento

  • Marca/desmarca los checkboxes según lo necesites
  • Puedes combinar múltiples tipos
  • Todos están marcados por defecto
  • Los cambios se aplican sin recargar la página

Filtro de URL (automático)

  • ?personaId=X - Filtra por persona
  • ?ramaId=Y - Filtra por rama
  • Los parámetros son procesados automáticamente

Vistas del Calendario

El calendario ofrece 3 vistas principales:

📅 Vista Mensual

  • Muestra el mes completo
  • Ideal para planificación a largo plazo
  • Ver patrones y distribución de eventos

📆 Vista Semanal

  • Muestra una semana con horas
  • Perfecta para ver detalles de tiempo
  • Identificar conflictos de horarios

📊 Vista Diaria

  • Muestra un día completo con horas
  • Máximo detalle y precisión
  • Planificación detallada

Controles de Navegación

  • < y > - Navegar entre períodos
  • Today - Ir al día actual
  • Selector de vista - Cambiar entre mes/semana/día

Detalles del Evento

Al hacer click en un evento, se abre un modal con la información:

Información Mostrada

  • Título - Nombre del evento
  • Tipo - ACTIVIDAD, CURSO, BINGO o CAMPAMENTO (con color)
  • Fechas - Inicio y fin
  • Alcance - General, Rama o Individual
  • Rama - ID de la rama asociada
  • Educador - ID del responsable
  • Beneficiario - ID de la persona a cargo
  • Nivel - Nivel de curso (si aplica)

Interacción

  • Haz click en cualquier evento para abrir el modal
  • Haz click en "Cerrar" o fuera del modal para cerrarlo
  • Los colores corresponden al tipo de evento

Información Técnica

Endpoints Utilizados

GET /api/ramas

Obtiene todas las ramas disponibles Respuesta: { "ramas": [...] }

GET /api/eventos/rango

Parámetros: - desde: LocalDateTime (ISO 8601) - hasta: LocalDateTime (ISO 8601) - personaId (opcional): Long - ramaId (opcional): Long - tipoEvento (opcional): String Respuesta: { "eventos": [...] }
